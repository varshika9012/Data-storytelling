This project analyzes a publicly licensed dataset of fatal motor-vehicle collision rates across all 50 U.S. states and the District of Columbia, alongside contributing factors (speeding, alcohol involvement, distraction, prior offenses) and state-level auto insurance premiums/losses. It runs a full pipeline — automated data-quality checks, statistical analysis (correlations, rankings, a premium-vs-risk gap metric), chart generation, and a professionally formatted Word report — entirely from code using pandas, NumPy, and Matplotlib for analysis and docx (Node.js) for report generation. The output report includes an executive summary, methodology, data-quality notes, key findings with visualizations, limitations, and actionable recommendations for insurance, policy, and public-safety audiences. Fully reproducible with one command (./run_pipeline.sh).
